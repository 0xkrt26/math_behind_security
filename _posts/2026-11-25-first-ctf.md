### Misc Task

The second task I solved was from the Misc section. The task had three folders inside:

```
├── battle
│   ├── python code of the battle
│   └── flag.txt (encrypted)
├── key
│   ├── a scrambled key
│   └── python code that scrambled the key
└── weapons
    ├── txt file with info about weapons (encrypted)
    ├── txt file with coordinates of the enemy (encrypted)
    └── python code that encrypted these txt files
```

The correct order of actions would have been:

1. Unscramble the key
2. Use the key to decrypt txt files from weapons
3. Give bomb coordinates into the battle.py
4. Get the flag

I am not a big fan of writing programs, which I would have to do if I wanted to unscramble the key, so I just skipped the step. And saved myself some time. Turns out the txt files in the weapon folder were encrypted using the Vigenère cipher. And as we know, that one can be cracked using Kasiski examination (which I wrote about [here](https://0xkrt26.github.io/math_behind_security/2026/09/16/vigenere.html)). It was a pretty long text, so this [online tool](https://www.dcode.fr/vigenere-cipher) found the key on the first attempt and decrypted the following:

I must admit I got a bit stuck here. Mostly because of my battle skills. The python file in the battle folder was asking for the bomb coordinates. I thought I either needed to find a bomb among the 1s or that I had only one bomb to drop. But after some brainstorming and more careful analysis (it was at this point that I substituted "one"s with "1"s), I noticed the pattern in the table: all the ones could be divided into pairs that were in the corners of a 3x3 matrixes.

So I gave in the following coordinates:

```
(2,4)
(10,4)
(20,4)
(30,4)

(5,10)
(15,10)
(25,10)

(10,16)
(20,16)

(5,22)
(15,22)
```

..and destroyed the Alien Armada!

### Other challenges and my struggles

As you might already know, I have a blog about cryptography, my main target was Crypto section. But all of the challenges there except for that easy one required connection to the server. I tried downloading ncat, but something didn't work out, so I focused on the tasks, that didn't require the connection, like the misc task above.

<div style="font-style: italic; color: #734f96;">

Yes, we were allowed to use AI as a search engine and I could look it up there. But I was still a bit too worried that it might be considered as cheating. And since I've joined a random team just a few minutes before the start, I didn't want to let anyone down by accidentally getting us disqualified. So I decided to leave the connection problem for later.

</div>

That's why I tried another misc challenge, that I wasted so so much time on. It was supposed to be the easy one by the way. The challenge folder had only a picture of a vertically squished QR code with the caption "Trust me, the closer you look the less you see."

My first idea was obviously to scan the QR code, however it gave no flag. Then I decided not to trust the caption and started analyzing the picture closer. I tried interpreting black and white lines as binary or morse code (it did make sense to me from how the lines looked). And I spent so much time on it that I swear I was already hallucinating the answer in morse saying "Never trust...". 

Eventually, I decided to google (one of the challenge sponsors btw) what options are there for image CTFs in general. That's when I found out about steganography. Though, analysis showed nothing hidden in the image. I got a hint from the organizers that I might be looking in the wrong place. So I tried running the analysis on the zipped folder itself. It also gave nothing. Already later at home, I opened the folder as a txt file and saw the flag.txt embedded there, but still didn't manage to extract it (unlike eight other teams).

After wasting so much time on the picture, I wanted to spend the last hour productively and try a few more challenges there were left. To be honest, my brain was already super tired after 7 hours of nonstop puzzle solving, so I couldn't manage the Diffie-Hellman task (even though I literally have a [post](https://0xkrt26.github.io/math_behind_security/2026/06/09/the-story-of-the-hash-function.html) about their construction, so this had some potential). And another one simply required too much time, which I didn't have anymore.

<br>

### Short sum up

I really liked the competition. Partially because my team got third place and a prize from another sponsor - Siemens. Also when I got home, I analysed the scoreboard again and noticed that even though I had the lowest score among my teammates, it was still bigger than the scores of some participants from the teams in second and first places, which means I wasn't that useless for the team either. All in all, I had a great Friday, met some interesting people, and got a cool sticker:)
